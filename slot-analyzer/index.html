プライバシーポリシー - Slot Analyzer

最終更新日: 2026年5月17日

Hiroyuki Takeda（以下「当方」）は、Slot Analyzer（以下「本アプリ」）におけるユーザーのプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーでは、本アプリにおける情報の取扱いについて説明します。

1. データを収集しません

本アプリは、ユーザーの個人情報を一切収集・送信しません。本アプリは完全にオフラインで動作し、サーバー通信、アカウント登録、ログインを必要としません。

  • 広告なし: 本アプリは広告を一切表示しません。広告SDK（Google AdMob 等）は搭載していません。
  • トラッキングなし: 本アプリはユーザーを追跡しません。広告識別子（IDFA）や App Tracking Transparency（ATT）は使用しません。
  • 第三者SDKなし: 解析・計測・広告等の第三者サービスSDKを一切使用しません。
  • 分析なし: 利用状況の分析やクラッシュレポートの外部送信を行いません。

2. アプリ内データの取扱い

本アプリで作成・記録されるデータ（機種データ、カウントセッション、設定推測の記録、アプリ設定等）は、すべてユーザーのデバイス内（端末ローカルストレージ）にのみ保存されます。これらのデータがデバイス外に送信されることはありません。当方がこれらのデータにアクセスすることはできません。

3. 第三者への情報提供

本アプリは情報を収集しないため、第三者への情報提供は一切行いません。

4. データの保存と管理

  • 保存場所: すべてのデータはユーザーのデバイス内にのみ保存されます。
  • データの削除: アプリをアンインストールすることで、デバイス上のすべてのアプリデータが削除されます。

5. 子どものプライバシー

本アプリは13歳未満のお子様を対象としていません。本アプリは個人情報を収集しないため、13歳未満のお子様から個人情報を収集することもありません。

6. プライバシーポリシーの変更

当方は、必要に応じて本プライバシーポリシーを変更することがあります。変更があった場合は、本ページを更新いたします。
