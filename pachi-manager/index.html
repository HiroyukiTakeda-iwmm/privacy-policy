プライバシーポリシー - Pachi Manager

最終更新日: 2026年9月12日

Hiroyuki Takeda（以下「当方」）は、Pachi Manager（以下「本アプリ」）におけるユーザーのプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーでは、本アプリにおける情報の取扱いについて説明します。

1. 収集する情報

本アプリでは、収支記録、実戦の途中経過、店舗・機種情報、貯玉・貯メダルの残高と取引履歴、メモ、添付画像および設定を端末内に保存します。これらの記録を当方のサーバーへ送信する機能はありません。

記録と集計はオフラインで利用できます。公開機種データの取得・更新時はGitHubへ通信し、IPアドレス等の通信に必要な情報が接続先へ伝わります。バージョン1.4以降のアプリ更新はApp Store経由で行います。開発者が収支・貯玉残高・メモ・添付画像をGitHubへ送信する処理はありません。広告SDKおよび広告目的のトラッキングは使用しません。

バージョン1.3以前にはExpoによる更新確認機能が含まれます。この通信では、ランダムなインストール識別子、更新のバージョン情報、起動失敗時のエラー情報がExpoへ送信される場合があります。バージョン1.4ではこの機能を取り除いています。

2. カメラ・写真ライブラリのアクセスについて

本アプリでは、収支記録に画像を添付する機能を提供しています。この機能を利用する際、カメラまたは写真ライブラリへのアクセス許可を求める場合があります。

  • カメラ: 収支記録に添付する画像を撮影するために使用します。
  • 写真ライブラリ: 収支記録に添付する画像を選択するために使用します。

撮影・選択された画像はアプリの保存領域へコピーして保持します。当方が画像を収集することはありません。端末のバックアップ設定により、画像を含むアプリデータがAppleのバックアップに含まれる場合があります。

3. 第三者への情報提供

公開機種データの配信にはGitHubを利用します。旧バージョンの更新配信にはExpoを利用します。ユーザーがエクスポートや共有を選択した場合は、選択した共有先へデータが渡ります。共有するデータと共有先を確認して操作してください。第三者サービスによる情報の取扱いは各サービスのプライバシーポリシーに従います。

4. データの保存と管理

本アプリの記録は端末内に保存されます。iOSのiCloudバックアップ等が有効な場合、アプリデータがAppleのバックアップに含まれることがあります。アプリでバックアップ対象からの除外を選択した場合は、保存データに除外設定を適用します。この設定は端末間の即時同期を提供するものではなく、既に作成されたバックアップを削除するものでもありません。

5. ユーザーの権利

  • データの削除: アプリ内の設定画面から全データを削除できます。また、アプリをアンインストールすることで、端末上のアプリデータが削除されます。既に共有・書き出したファイルやAppleのバックアップは別途管理してください。
  • データのエクスポート: アプリ内の設定画面から収支・実戦・貯玉台帳をJSON形式で書き出せます。CSV形式では収支記録と現金・貯玉換算の内訳を書き出せます。JSON内の画像参照は画像ファイル本体の代わりにはならないため、画像の引き継ぎは端末バックアップをご利用ください。

6. 子どものプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満のお子様から意図的に個人情報を収集することはありません。

7. プライバシーポリシーの変更

当方は、必要に応じて本プライバシーポリシーを変更することがあります。変更があった場合は、本ページを更新いたします。
